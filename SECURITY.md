# Security Policy

Please **do not** report security vulnerabilities in public issues.

Report them privately through [GitHub Security Advisories](https://github.com/wianger/bilingo/security/advisories/new). Include steps to reproduce and the affected version. You can expect an initial response within a week.

Areas of particular interest: injection of untrusted translation output into pages, leaking API keys or page content to unintended parties, and extension permission misuse.
